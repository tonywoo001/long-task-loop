# 结构化汇报规范（references/report-spec.md）

本文件是三个交棒点汇报格式的唯一定义：奠基完成汇报、循环交付汇报、升级人工汇报。三段对应时必须按本规范输出，不得以自由散文替代。

## 一、通用规则

- **单一样式**：模板行不增、不删、不改序；某行确无数据写「无」，不省略该行。
- **逐项重复行**：模板里标注「按层 A 表逐项重复」的行，按实际交付物项数重复，一项一行；层 A 表为空时保留一行写「无」。
- **数字实报**：所有计数取自总控文档实际记录行，不估算、不凭会话记忆。
- **链接可点**：文档一律粗体 markdown 链接 `**[标题](链接)**` 呈现，渲染后用户可直接点击；禁止裸贴 URL、禁把 URL 与标题拆成两行。仅当输出环境确不渲染 markdown（纯文本终端）时退回「标题：URL」单行裸链接。
- **结论行收尾**：最后一行必须是「👉 下一步」，明确说清轮到谁、做什么、以什么形式（评论、会话指令）。
- **占位符全角【】**；汇报输出在当前会话，是给用户的界面，不写进总控文档正文（轮次日志照常记账，两者不互替）。
- **术语零裸露**：汇报是用户界面，禁写工作流内部协议代号（铁律编号除外——铁律编号在总控文档内有定义，可以照写）。决策编号（D-N、S-N）、事项编号（T-N）、细分目标编号（G0-N）、项目约束编号（约 N）、轮次号（R 加数字）可以照写。
- **汇报之外的补充说明不超过五行**；细节引导用户看总控文档对应章节，不在会话里复述全文。

## 二、奠基完成汇报（段二出口 · 签批三行誊写完成后输出）

```text
【奠基完成汇报】long-task-loop
📄 总控文档：**[【标题】](【链接】)** · 文档版本 v0.0（开档态）
🎯 目标体系：G0【终极目标一句话】 · G0-N 细分目标【N】条，逐条已带判据
💡 思路基线：候选思路【N】个（实质不同） · 选定【思路名】 · 共识凭证已登记
🔒 三锁签批：目标锁｜事实基线锁｜方案框架锁 三行齐全，评论凭证已登记
🚪 就绪门：全部子判据通过，评估结论已誊写就绪门与签批记录章
⚠️ 缺口处置：补齐清零【N】项 · 豁免【N】项（凭证已登记，风险随交付）
📌 循环前置待办：【N】项（未清零不开轮，清单见待办登记章）
🔁 方案框架：访谈档位【全量｜快速】 · 项目约束【N】条 · 最大轮次【N】 · Token 预算【数值｜未设】
👉 下一步：你说「开始循环」并附本总控文档链接（这句明确的启动指令是开轮凭证，就绪门通过不等于授权），循环段接手
```

## 三、循环交付汇报（段六终点 · 交付登记完成后输出）

```text
【循环交付汇报】long-task-loop
📄 层 A 交付物：**[【交付物名与标题】](【链接】)** · revision【X】· 已获批，评论凭证已登记（本行按层 A 表逐项重复；产研工具类默认两行＝设计方案与实现方案）
🔁 轮次：R1 至 R【N】 · 差距累计【N】项全关闭（含重开【N】项）· 总控文档定格 v1.0
🚪 三门：目标覆盖门｜独立评审门｜开工就绪门 全部通过（三门全过才发起终局批）
🧾 终局批：三级决策【N】条（确认【N】· 推翻后按回滚锚重做【N】）· 二级决策【N】条（确认【N】· 推翻【N】）· 一级留痕【N】条 · 豁免确认【N】项
🧷 终局登记：批准评论链接、日期、各层 A 交付物 revision 逐项齐全
🏁 收敛类型：【定稿收敛｜带决收敛（含阻断实施项：是｜否）】
⚠️ 随交付风险：豁免项【N】条，全文见实现方案「风险与未知项清单」
👉 下一步：全部获批层 A 交付物交下游实施；本循环终止，总控文档与过程材料不随交付
```

## 四、升级人工汇报（循环停滞、达最大轮次或 Token 预算耗尽、停止自治时输出）

```text
【循环升级人工汇报】long-task-loop
📄 总控文档：**[【标题】](【链接】)** · 文档版本 v0.【N】
⛔ 停因：【连续两轮零关闭零新增｜已达最大轮次【N】｜Token 预算耗尽】
🔁 轮次：已跑 R1 至 R【N】 · 差距已关闭【N】项 · 未关闭【N】项（清单见循环区章）
🧾 决策账：二级决策已记【N】条（状态：已执行待批）· 三级挂起【N】条（待你拍，详见影子决策清单章 7.1 节）
📌 待办账：循环前置待办【N】项 · 业务阶段待办【N】项
👉 下一步：请四选一——【扩轮至新最大轮次（写明数字）｜加预算或改预算上限至（写明数值）｜转收敛评审｜终止任务】；凭证分两档——扩轮：会话指令直接生效，AI 登记简洁扩轮记录（原上限、新上限、指令原文、指令时间）即为凭证；加预算、转收敛评审、终止任务：总控文档评论链接为凭证（口头同意不作凭证）；两档均须登记停滞解除行后循环才恢复
```
